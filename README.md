# Retina Woods

https://aidanlambournecreatesstuff-ops.github.io/ma-1800-web-art-project-code/

# Project Description
Retina Woods is a web-based abstract artwork that presents the social transparency and access of the internet under a horror lens. The non-linear connection of HTML pages creates an environment of being lost. The scary images I edited and inserted into the project add to the horror aesthetic. 

# Case Studies
I was immediately inspired by JODI’s wwwwwwwww.jodi.org (1995) for the creative and abstract use of hyperlinks. Where her artwork makes you feel confused as you delve deeper into the pages, I wanted the users to feel uncomforable and afraid. 

I was also inspired by Vivian Selbo's Vertical Blanking Interval (1996) for the interesting use of imagery. The first page tells a story without words, where text only appears on subsequent pages through exploring. I wanted to create a narrative that isn't led by words.
